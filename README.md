# 🎯 PDAN8412 – Programming for Data Analytics 2

## 📖 Overview
Welcome to PDAN8412 – Programming for Data Analytics 2! 🚀

This repository contains structured content for the module, including:

* 🚀 Lecture resources which will be updated as we go
* 📝 Activities and coding exercises
* 📚 Information about the module
* 🧪 Practical notebooks and examples
* 🧠 Support material for the PoE

This module builds on PDAN8411 and focuses on working with larger and more complex datasets using Python, Spark, machine learning and deep learning.

The goal is not only to run notebooks, but to understand the full data analytics workflow: loading data, cleaning data, exploring it, preparing it for modelling, training models, evaluating results and explaining findings clearly.

## 📂 Repository Structure
Each folder corresponds to a module topic. Inside, you will find activities, notebooks, resources and examples that we will work through during the semester.
Content will be added and refined as we go.

You can expect work around:
* Getting started with PySpark
* Exploratory data analysis with larger datasets
* Neural-network foundations
* Recurrent Neural Networks and LSTMs
* Logistic Regression from scratch
* Generative models, including GANs
* A short bridge into modern GPT-style models
* CNNs and image classification using TensorFlow
* PoE preparation and submission guidance

## 😎 What’s the reason for this module in BCAD?
By now, you have already worked with Python, data analytics and machine learning foundations. PDAN8412 is where we move further into scalable and more advanced analytics.

In this module, we will:
* 🔥 Use Apache Spark to work with larger datasets
* 📊 Perform exploratory data analysis on structured and text data
* 🧹 Clean and prepare data for machine learning
* 🧠 Build an understanding of neural networks
* ✍️ Work with text data for sequence modelling
* 🔁 Explore RNNs and LSTMs
* 📈 Build Logistic Regression from scratch
* 🖼 Work with CNNs and image classification
* 🤖 Explore generative AI ideas, including GANs and GPTs
* 📝 Practice writing clear notebook explanations and short reports

The main aim is to help you become more confident with the type of practical, evidence-based work expected in data analytics projects.

## 🏆 How will the module be taught?
This module is practical. You will learn by doing.

* 🎓 The focus is on preparing you for real data analytics and machine learning work, not just passing assessments.
* 💡 You will write code, make mistakes, debug errors and improve your work.
* 🧪 Most sessions will involve practical notebooks and activities.
* 📊 You will be expected to explain what your code does and what your results mean.
* 🧠 Industry context, responsible AI use and good data practice will be emphasised throughout.
* 📝 The PoE will be supported through the activities, but you are responsible for completing and submitting your own original work.

If you engage consistently, you should leave this module with practical notebooks and project work that demonstrate Spark, machine learning and deep learning skills.

To do well, you should:
